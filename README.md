### Página de Login Animada

Este projeto foi desenvolvido por mim como forma de estudo e prática de desenvolvimento web para o curso de Engenharia de Software. 

### 📌 Créditos e Referências

O código e o design desta aplicação foram baseados no tutorial do canal **AsmrProg**: 

* **Vídeo Utilizado:** [ASMR Programming - Animated Login Page - No Talking](https://www.youtube.com/watch?v=PlpM2LJWu-s)
* **Código Original:** [Modern-Login no GitHub](https://github.com/AsmrProg-YT/Modern-Login)
* **Canal do Criador:** [AsmrProg no YouTube](https://www.youtube.com/@AsmrProg-YT)

* CSS3 (Flexbox e Animações com Keyframes)
